# Results Directory

This directory contains output files generated by the analysis notebooks, including visualizations, plots, and analysis results.

## Purpose

All generated output files (PNG plots, PDFs, result CSVs, etc.) are stored here to keep the project root clean and organized.

## Contents

### Visualization Files (PNG)

The notebooks generate various plots and figures:

**Model Performance Plots:**
- `RF_both_hospitals_AUC_iter_.png` - Random Forest AUC curves
- `LR_PR_holdout.png` - Logistic Regression PR curves
- `*_AUC_iter_*.png` - AUC iteration plots
- `*_PR_iter_*.png` - Precision-Recall iteration plots

**Feature Importance Plots:**
- `*_feat_importances_*.png` - Feature importance visualizations
- `both_feat_importances_.png` - Combined feature importances
- `ICD_*`, `CPT_*`, `kw_*` - Feature-specific importance plots

**Comparison Plots:**
- Hospital-specific comparison plots
- Model comparison visualizations
- Train/test performance comparisons

### Generated by Notebooks

Different notebooks generate different output files:

- **Step 10-12**: Random Forest test results and plots
- **Step 15-17**: Feature-specific Random Forest results
- **Step 18**: Graph generation for comparisons
- **Step 22-25**: Logistic Regression results and plots
- **Various steps**: Feature importance CSVs and visualizations

## Using Results in Notebooks

To save results programmatically, use the config module:

```python
import config
import matplotlib.pyplot as plt

# Create your plot
plt.figure()
# ... plotting code ...

# Save to results directory
plt.savefig(config.get_results_path('my_output_plot.png'))
```

This automatically:
1. Creates the results/ directory if it doesn't exist
2. Saves the file in the correct location
3. Works consistently across different environments

## Git Tracking

By default, result files are tracked by git. If you want to exclude them (recommended for large result sets):

Uncomment these lines in `.gitignore`:
```
# results/
```

Or selectively ignore file types:
```
results/*.png
results/*.pdf
results/*.csv
!results/README.md
!results/.gitkeep
```

## File Organization Tips

Consider organizing results by analysis type:

```
results/
├── model_performance/
│   ├── AUC_curves/
│   └── PR_curves/
├── feature_importance/
│   ├── ICD/
│   ├── CPT/
│   └── keywords/
└── comparisons/
```

You can create subdirectories as needed and use `config.get_results_path('subdir/file.png')`.

## Regenerating Results

All result files can be regenerated by running the analysis notebooks in order. To start fresh:

1. Delete all files in `results/` (except README.md and .gitkeep)
2. Run notebooks Step 1-26 in sequence
3. Results will be regenerated
