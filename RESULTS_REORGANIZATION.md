## Configuration Updates

**config.py** has been updated with enhanced results directory support:

```python
# Results directory location
RESULTS_DIR = PROJECT_ROOT / 'results'

# Enhanced helper function
def get_results_path(filename):
    """
    Get the full path to a results file.
    Creates the results directory if it doesn't exist.
    """
    RESULTS_DIR.mkdir(parents=True, exist_ok=True)
    return str(RESULTS_DIR / filename)
```

## Usage for Future Results

### In Notebooks:

**Old way (hardcoded):**
```python
plt.savefig('my_plot.png')  # Saves to project root
```

**New way (recommended):**
```python
import config
plt.savefig(config.get_results_path('my_plot.png'))  # Saves to results/
```

### Benefits of Using config.get_results_path():

1. **Automatic directory creation** - No need to check if results/ exists
2. **Consistent location** - All results go to the same place
3. **Portable** - Works regardless of where code is run from
4. **Organized** - Can use subdirectories: `config.get_results_path('plots/auc_curve.png')`
